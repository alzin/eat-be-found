# 膳 Web — 飲食店専門 Webリニューアル・MEO運用

Marketing site for a restaurant-focused web renewal and Google Business Profile (MEO)
service. Built as a static single-page app and published to GitHub Pages.

**Live site:** https://alzin.github.io/eat-be-found/

## Stack

- **React 19** + **TypeScript** (strict)
- **TanStack Router** — file-based routes in `src/routes/`, per-route code splitting
- **Tailwind CSS v4** via `@tailwindcss/vite`
- **Vite 8** — static build to `dist/`
- **Bun** — package manager and task runner

## Getting started

```bash
bun install
bun run dev
```

The dev server runs at http://localhost:5173/eat-be-found/ — note the sub-path, which
mirrors how GitHub Pages serves the site.

## Scripts

| Command | Description |
| --- | --- |
| `bun run dev` | Start the dev server |
| `bun run build` | Build to `dist/` and write the SPA `404.html` fallback |
| `bun run preview` | Serve the production build locally |
| `bun run typecheck` | `tsc --noEmit` |
| `bun run lint` | ESLint |
| `bun run format` | Prettier |

| Path | File |
| --- | --- |
| `/` | `src/routes/index.tsx` |
| `/services/web-renewal` | `src/routes/services.web-renewal.tsx` |
| `/services/meo` | `src/routes/services.meo.tsx` |
| `/services/seo` | `src/routes/services.seo.tsx` |

`src/routeTree.gen.ts` is generated by the TanStack Router Vite plugin — do not edit it.

## Deployment

Every push to `main` triggers `.github/workflows/deploy.yml`, which builds the site and
publishes `dist/` to GitHub Pages.

Because Pages serves a project site from `/<repo>/`, `vite.config.ts` sets
`base: "/eat-be-found/"` and the router picks that up via `import.meta.env.BASE_URL`.
To deploy at a domain root instead, build with `BASE_PATH=/`:

```bash
BASE_PATH=/ bun run build
```

GitHub Pages has no server-side routing, so `bun run build` copies `index.html` to
`404.html`. Pages serves that for unknown paths, letting the router handle deep links
such as `/services/meo` on a cold load.
